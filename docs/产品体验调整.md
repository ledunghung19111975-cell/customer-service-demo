# 产品体验说明

产出 Agent：Codex

## 页面与角色

客户页面提供咨询、订单查询、售后申请和进度跟进；坐席处理接待与工单，运营维护知识、流程和质量问题。工作台展示当前工作空间的事项、客户确认、待处理工单与复核待办，数值来自已保存的业务状态。

客户通过 `?view=customer#playground` 进入独立页面，可直接描述问题，也可从“服务规则”“订单物流”“申请售后”或“我的订单”发起咨询。服务与订单操作会立即发送对应问题。页面只保留客户服务内容；“我的咨询”提供历史咨询入口，发起新咨询后仍可回到原事项和工单。

后台“渠道预览”保留会话选择、折叠的执行记录和坐席会话入口。客户与后台共享同一浏览器工作空间，演示时使用一个标签页切换地址。客户 URL 不承担登录认证、权限隔离或跨设备同步。

## 咨询与处理结果

机器人回答展示适用的知识依据，订单查询展示查询结果，售后申请通过填写、预览和明确确认后创建工单。受理卡片可以继续查看同一事项的处理进度，避免重复登记。

“受理成功”“处理完成”“客户确认”分别记录对应结果。坐席接管后由当前坐席回复；工单的客户说明与内部备注、结果证据分开展示。聊天结束后仍可补充工单、查看结果或提出异议，未完成事项继续保留。

## 草稿测试与发布

知识和流程先保存草稿，通过相匹配的回归后发布。订单查询的“查询超时”由“草稿测试”中的响应选项提供，仅注入测试副本，不修改草稿或已发布配置。

历史版本保留原状态。已有配置含有查询超时设置时，可恢复草稿正常查询，重新回归并发布；已有会话继续保留其流程版本，接待容量和工具启停按实时设置执行。

## 系统设置与数据

“系统设置”管理服务组状态、接待容量、当前坐席和订单查询开关。调整时填写变更原因，保存后对后续接待动作生效。

“导出工作空间”下载包含会话、事项、工单及配置的 JSON 文件。“高级维护”中的“清空业务记录并恢复配置”需要再次确认，清空业务记录和输入草稿，恢复内置知识与接待配置，不重新生成历史会话。清空前应导出需要保留的数据；存储异常时禁止清空。

兼容读取保留保存键、核心对象编号和业务关系。已知内置文案需要调整时先备份原状态，不对客户和坐席手写消息、自定义知识或未提交表单执行全局替换。存储失败会显示提示，已有数据无法读取时不覆盖原始保存值，原始保存值仍可读取时支持导出副本；该副本不包含临时工作空间的操作。

## 接入与实现边界

模型服务、移动渠道、企业微信和外部业务系统在接入页面显示实际状态。当前问答依赖本地规则与模板，业务记录保存在浏览器中，尚未接入真实模型、订单、支付、退款或通知系统。

品牌、客户、订单、规则和处理结果均为虚构样例。界面用于验证服务流程；真实部署需要服务端身份鉴权、订单归属校验、持久化、并发控制与业务接口。验证命令和已记录的覆盖范围见 [README](../README.md) 与 [验收矩阵](验收矩阵.md)。
