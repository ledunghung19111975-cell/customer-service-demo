# 运行与验证说明

源码入口：[customer-service-demo](https://github.com/ledunghung19111975-cell/customer-service-demo)。前端使用 HTML、CSS 与 JavaScript，无需 npm 安装或构建。在线托管尚未部署。

## 本地启动

在包含 `index.html` 的目录运行：

```bash
python3 -m http.server 8768 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8768/`。保持该进程运行，按 `Ctrl+C` 停止。启动环境需要 Python 3；日常演示不需要 Node.js、Playwright 或模型密钥。

## 更新与验证

更新已有检出前，先用 `git status --short` 检查本地修改并妥善保存。获取当前主分支后运行：

```bash
node --test tests/*.test.cjs
node --check app.js
node --check engine.js
node --check flow-graph.js
node --check flow-editor.js
```

可用 `shasum -a 256 -c MANIFEST.sha256` 校验分发文件。浏览器测试的可选依赖与命令见 [README](../README.md)，实际覆盖与限制见 [验收矩阵](验收矩阵.md)。历史评审报告中的哈希、测试数量与截图仅适用于其记录的基线。

## 使用 Git 同步

项目使用独立 Git 仓库，默认分支为 `main`，远端为 `git@github.com:ledunghung19111975-cell/customer-service-demo.git`。推送需要事先配置对该仓库有写权限的 SSH 身份；网页登录状态不会自动供命令行使用。

在项目仓库内，确认本地修改已妥善保存后，用 `git pull --ff-only` 获取远端更新。修改源码或分发文档后，完成相关检查，并更新 `MANIFEST.sha256` 与本地交付 ZIP，再提交：

```bash
git status --short
git add .
git diff --cached --stat
git commit -m "说明此次更新"
git push
```

`.gitignore` 排除工作记录、交付 ZIP、历史 PNG 截图和本地环境配置；提交前仍需检查暂存文件。私钥只保存在本机 SSH 目录，不放入项目。下载 ZIP 不包含 Git 历史；需要版本管理时，应通过 `git clone` 获取仓库。
