# 知序 · 通用智能客服演示 V3

用于智能客服产品经理面试与产品评审的可操作原型。以虚构电商品牌“青禾生活”为例，连通客户咨询、服务分发、售后受理、人工接续、工单进度、结果确认，以及后台知识、流程发布和质量整改。

前端包含十个页面，使用原生 HTML / CSS / JavaScript。**问答由本地规则驱动，没有接入真实大模型、RAG、业务系统或退款。**

## 启动

解压后保持目录完整，在包含 `index.html` 的目录打开终端：

```bash
python3 -m http.server 8768 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8768/`。运行时不需要安装 npm 包或构建；使用本地服务需要 Python 3。按 `Ctrl+C` 停止服务。端口被占用时，同时修改命令和浏览器地址中的端口。

建议通过固定的本地 HTTP 地址演示。直接双击 `index.html` 不涉及模块加载或外部资源，但不同浏览器对 `file://` 本地存储的处理可能不同，此方式未列入验收范围。仓库链接是源码入口，不等于已部署的在线 Demo；在线托管尚未部署。

## 先演示什么

进入“体验中心”后点击“开始咨询”，再点“只看客户窗口”。先输入：

```text
不要转人工，我只问退货规则
```

再输入：

```text
查物流 SO20260926001，再申请退货
```

页面会分别保留查询事项和售后事项。点击“填写并确认售后申请”，检查描述并确认提交；切回运营视角，打开对应坐席会话和工单。分配负责人、要求补充材料、填写处理说明和模拟结果证据，再回到客户窗口确认结果。**查到了订单、登记了工单、结束了聊天，都不等于完成了售后。**

详细操作、讲解话术与备用异常场景见 [演示脚本](docs/演示脚本.md)。页面右上角也有“演示路线”。

## 可操作能力

| 环节 | 可以现场验证的行为 |
| --- | --- |
| 客户入口与分发 | 三个服务入口；固定多事项示例；拒绝转人工的否定表达；信息采集被插问后继续 |
| 服务事项 | 会话、事项、工单分离；逐项确认；未完成事项不随聊天结束消失 |
| 售后受理 | 表单预填、提交预览、明确确认、防重复；不自动退款 |
| 人工接续 | 当前处理人回复权、在线／满载／离线模拟、旧会话读取实时状态、取消排队与留单 |
| 工单 | 分配、补充、完成证据、内部备注与客户说明分开、结束聊天后补充、完成后异议与重开 |
| FAQ 与知识治理 | 标准问题、答案、来源、范围、时效和维护人；草稿与现行版本分离；回归后发布与停用 |
| 流程编排 | 七个固定节点的参数配置、单条测试、十条发布回归、新会话绑定版本、恢复历史配置为草稿 |
| 质量整改 | 原问题线索 → 人工复核 → 知识草稿 → 回归发布 → 原问题复验 → 演示范围验收 |
| 工作台 | 本地事项与待办计数；事项结果与会话结束分别计数 |

## 运行测试

逻辑测试使用 Node.js 内置测试框架：

```bash
node --test tests/engine.test.cjs tests/ui.test.cjs
```

浏览器测试需要 Python Playwright 和 Chromium。测试不是日常打开 Demo 的前置条件。已装好这些工具后，先启动本地 HTTP 服务，再执行：

```bash
python tests/browser_smoke.py --url http://127.0.0.1:8768
```

受限渲染环境也可使用离线挂载模式：

```bash
python tests/browser_smoke.py --offline
```

追加 `--screenshots` 可保存成功场景截图；不加此参数仍执行全部行为断言。截图会等待短暂提示消失，所以运行时间更长。

当前验证：**85 项核心逻辑与 3 项界面逻辑测试通过。** 两类测试均在本地执行，不调用模型或业务接口。真实 HTTP 页面验收与证据版本见 [验收矩阵](docs/验收矩阵.md)。

`tests/evidence/` 中的 78 项逻辑测试和 12 项离线浏览器报告来自外部 V3 修订包，保留作历史证据；离线浏览器使用模拟存储，不能证明真实 Origin 持久化。HTTP 模式不执行仅离线适配器支持的 B11/B12 两项故障／恢复测试。

## 演示数据与边界

样例订单：`SO20260926001`（运输中）、`SO20260926002`（待发货）。日期、人物、规则、坐席、联系方式、业务结果与统计均是虚构样例。无需真实登录，请勿输入真实客户资料、密钥、订单或支付信息。

V3 使用独立存储键 `zhixu-customer-demo-v3`，不会自动迁移或覆盖旧版 `zhixu-customer-demo-v1`。正常保存时，数据仅属于当前浏览器、当前访问地址；不同浏览器、域名、端口或电脑不共享。**用一个标签页切换角色演示，不要用多个标签页同时写入。** 多标签页锁、跨设备同步和多人协作不在本版保证范围内。

“只看客户窗口”仅为展示切换，不是安全隔离。所有本地数据仍在同一个前端状态中；真正的客户归属、租户权限、坐席互斥与幂等必须由服务端保证。页面不发送网络 API 请求，也不会发送短信、邮件或实际退款。

本地保存失败会显示“当前操作仅保留至页面关闭”。右上角“重置演示”需要确认，仅重置 V3 样例及操作，不清除其他应用或旧版数据。
