# 知序 · 通用智能客服前端演示

产出 Agent：Codex

用于产品方案评审与交互演示的静态前端，采用 HTML、CSS 和 JavaScript，无第三方前端依赖，无需 npm install 或构建。

## 打开方式

1. 解压整个压缩包，保持文件目录结构。
2. 双击 index.html 可开始体验。
3. 如需使用本地 HTTP 服务，在解压后的 customer-service-demo 文件夹中打开终端，运行：

```bash
python3 -m http.server 8768 --bind 127.0.0.1
```

再访问 [本地演示](http://127.0.0.1:8768/)。需要本机已安装 Python 3；端口被占用时，可把命令和网址中的 8768 一起改成其他空闲端口。

127.0.0.1 只供当前电脑访问。给其他人演示时，可直接发送此压缩包，让对方解压打开；GitHub 仓库用于分享源码，在线访问网页需要另行部署。

## 页面与能力

- 工作台：查看演示数据和服务概况。
- 体验中心：模拟客户咨询、知识回答、订单查询、转人工与提交问题。
- 机器人配置：设置名称、说明和欢迎语。
- 流程编排：调整固定七节点模板的参数，测试草稿并发布配置。
- 知识库：新增、编辑、发布与停用知识。
- 会话中心：模拟坐席接管、回复、结束与建立关联工单。
- 工单中心：模拟负责人分配、状态流转和客户补充材料。
- 质检与日志：查看演示问题、执行轨迹与处理记录。
- 接入与集成：说明拟接入能力及接口边界。
- 系统架构：展示架构分层。

## 建议演示顺序

1. 点击右上角“体验机器人”，进入体验中心并“开始咨询”。
2. 输入“七天无理由退货有什么条件？”，查看回答和知识来源。
3. 输入“帮我查订单”，再输入模拟订单号“SO20260926001”，查看补充信息后的查询结果。
4. 输入“转人工”，通过会话入口切换到坐席视角，接管并回复。
5. 从会话创建工单，在工单中心分配、推进，并查看关联会话中的结果。
6. 在流程编排修改参数，运行草稿测试并发布，再创建新会话观察配置生效。

页面右上角“重置演示”会清空此应用在当前浏览器地址下的演示数据并恢复示例，操作前有确认。

## 演示边界

所有客户、订单与统计均为模拟数据。问答由本地关键词与模板驱动；工单、知识、配置与会话保存在当前浏览器的 localStorage 中，不在不同电脑或不同访问地址之间同步。浏览器禁止本地保存时，页面会提示数据仅保留到关闭。

流程为固定模板，当前支持参数配置与发布模拟。人工在线状态也由演示配置控制。真实模型、RAG、数据库、业务接口、渠道、身份权限和多人协作均未接入。

完整产品方案中的服务事项、多诉求处理、实时人工容量、紧急版本处置与整改验收关联仍属于待实现需求。此交付包用于验证现有前端交互。
